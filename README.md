# Machine-Learning-Enabled-Multiparameter-Weak-Measurement-Metrology-for-Phase-Gradient-Metasurfaces

This repository provides a machine learning pipeline for weak measurement data, aimed at regressing three physical parameters: the amplitude ratio, the phase difference, and the rotation angle. The model construction and training are implemented in code.py, while test.py loads the trained .pth checkpoints to perform inference and generate evaluation outputs. The dataset is organized through the index file dataset_index_fast_v174.csv, and the dataset generation workflow is provided in get dataset.nb. The trained checkpoints best_b.pth, best_phi.pth, and best_zeta.pth correspond to the amplitude ratio, phase difference, and rotation angle, respectively. The real experimental test outputs are stored as CSV files as shown in the screenshot, including Detail_b_Test.csv, Detail_phi_Test.csv, and Detail_zeta_Test.csv, together with their Train and Val counterparts. The code is intended to run under Python 3.10 with CUDA 12.1 for GPU acceleration, under the constraint that the network definition used for inference must match the one used during training to avoid checkpoint incompatibility.
